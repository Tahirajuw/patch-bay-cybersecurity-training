# Patch Bay — Interactive Cybersecurity Training Simulator

**Investigate. Detect. Defend. Learn.**

Patch Bay is a browser-based cybersecurity training simulator designed to help learners develop practical security analysis and incident response skills through interactive, scenario-based challenges.

Instead of simply reading about cybersecurity, users take the role of a security analyst, investigate incidents, make decisions, fix vulnerabilities, and earn experience points (XP).

## 🚀 Features

- **Interactive Incident Queue:** Work through six realistic cybersecurity incident scenarios.
- **SQL Injection:** Identify an SQL injection vulnerability and learn how parameterized queries prevent attacks.
- **Password Security:** Evaluate password strength and understand offline password cracking.
- **Phishing Detection:** Investigate suspicious emails and identify common phishing indicators.
- **Cross-Site Scripting (XSS):** Review code, identify vulnerabilities, and learn output encoding.
- **Log Analysis:** Investigate server logs, detect brute-force attacks, and identify compromised accounts.
- **Firewall Configuration:** Apply firewall rules using default-deny and least-privilege principles.
- **XP & Ranking System:** Earn up to 100 XP per incident and progress through analyst ranks.
- **Hints & Explanations:** Receive guidance and detailed explanations after completing challenges.
- **Progress Tracking:** Save completed incidents and scores in your browser.
- **Responsive Design:** Use the simulator on desktop, tablet, and mobile.
- **Dark Mode Support:** Automatically adapts to your system's color preference.

## 💻 Getting Started

### Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Rename `Patch Bay.html` to `index.html`.
4. Double-click `index.html` to open it in your browser.
5. Start investigating cybersecurity incidents!

### Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/patch-bay-cybersecurity-training.git
```

Open the `index.html` file in your browser.

## 🎮 How to Play

1. Select an incident from the incident queue.
2. Read the incident description.
3. Investigate the vulnerability or security event.
4. Complete the interactive challenge.
5. Use hints when needed.
6. Earn XP and read the security explanation.
7. Progress through all six incidents.
8. Check your final shift report and analyst rank.

## 🏆 Ranking System

| Rank | Completion |
|---|---|
| Trainee | Below 40% |
| Analyst | 40%–69% |
| Senior Analyst | 70%–89% |
| Incident Lead | 90% or above |

**Maximum score:** 600 XP.

## 📱 Responsive Design

Patch Bay is designed to work across different screen sizes, with a flexible incident queue and an adaptable training workspace.

## 🔒 Privacy & Data

- Progress is saved locally in the user's browser using Local Storage.
- Password-strength examples are evaluated within the browser.
- No backend or account registration is required.
- The application is an educational simulation, not a live security testing platform.

## 🎯 Learning Objectives

By completing Patch Bay, learners can practice:

- Understanding SQL injection and secure database queries.
- Recognizing weak passwords and improving password security.
- Identifying phishing emails and suspicious links.
- Detecting and preventing cross-site scripting.
- Analyzing authentication logs and brute-force attempts.
- Applying firewall policies and least-privilege principles.

## ⚠️ Disclaimer

Patch Bay is an educational cybersecurity simulation. All incidents, organizations, IP addresses, and scenarios are fictional or illustrative. The simulator should be used for learning and awareness, not for testing or attacking real systems.
